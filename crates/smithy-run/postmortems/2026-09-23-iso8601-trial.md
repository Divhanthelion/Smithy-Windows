## What was asked

> months rejected), with unit tests and a small CLI binary that prints the
> number of seconds.

## What went well

- **Checks were the ground truth.** T1 was committed only after the runner
  ran the build, the Task's filter (12 tests) and the full suite itself.
- **The judgments were right.** Guardrail let an ordinary intent through;
  "done" sent back an answer that had not done the work (0.23); loop stopped
  a stuck model twice; next-move escalated a missing toolchain; cheat
  accepted a legitimate template removal.
- **Research quality was high.** Both notes quoted primary sources verbatim,
  checked mechanically; the T2 note said plainly which conclusion rested on
  ISO-derived profiles because ISO's own text is paywalled — and caught a bug
  in T1's code (`W` ranked between `M` and `D`).
- **Nothing was lost.** Crash, escalation and interruption all left the
  work stashed and a report on the branch.

## What went wrong, and what changed

| # | Cause | Effect | Status |
|---|---|---|---|
| 1 | Run started from a shell without `~/.cargo/bin` (operator error) | 22 min on a Task that could not build | **Fixed** — `preflight` checks every toolchain program before planning |
| 2 | Planner split a small library into 6 Tasks, each with research | ~an hour of research per Task | **Fixed** — the plan is sized to the work (1–3 Tasks for a small library, up to 12 for a large system); every research question passes Jev's "needs outside sources?" before it runs, so what the model already knows is not researched |
| 3 | Every question got the full adversarial `/research` method | 30+ min per question | **Fixed** — each question carries a depth that sets its method and time: lookup 8 min, decision 20 min (both `/pointed-research`), deep 45 min (full `/research`); research may spend a third of the Run's hours (`--research-minutes` overrides), so big projects get more, not less |
| 4 | Research read without writing | a 30-min turn produced nothing | **Fixed** — draft early; nudged at 12 tool calls without a note |
| 5 | Resume re-researched a draft note | would have cost 30 min | **Fixed** — what a Run researched is reused whatever the note's status |
| 6 | `cite_check` rejected dense quotes (a regex, a document number) | 2 good findings marked unverified | **Fixed** — 4 words *or* 20 characters |
| 7 | `git stash list` refused | a wasted step | **Fixed** |
| 8 | **No prefix caching on vLLM** | every request recomputed ~52 k tokens: 14.8 M in all — most of the heat | **Open** — the new Thor recipe serves with `--enable-prefix-caching` |
| 9 | One turn ran 57 min before any check; the model wrote the whole grammar in T1 | no checkpoint for an hour; scope creep | **Fixed** — the Task's checks run as the model writes and end the turn when they pass; a build turn returns to the runner after 20 min either way |
| 10 | The runner kept no conversations | this post-mortem is reconstructed from decision records | **Fixed** — Run logs: `--log` off, events or full (default full), outside the repo; `events.jsonl` times every request, tool call and check; `sessions/` keeps every conversation |
